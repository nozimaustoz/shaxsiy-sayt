# CLAUDE.md

## Loyiha
Xusnidinova Nozima Ashurovna — oliy ta'lim o'qituvchisining shaxsiy vizitka sayti.
Bitta sahifa: hero, xizmatlar (3 ta alohida seksiya), loyihalar, aloqa.
Maqsad — hamkasblar, talabalar va tashkilotlar uchun professional taqdimot.
Muloqot va sayt matnlari o'zbek tilida (lotin yozuvi, apostrof: o', g').

## Uslub
- Ohang: professional, minimalistik, education stili. Ortiqcha bezak, animatsiya, emoji yo'q.
- Ranglar faqat `style.css` boshidagi CSS o'zgaruvchilari orqali. Yangi rangni to'g'ridan-to'g'ri
  yozma — token qo'sh: `--bg --card --ink --muted --line --accent --accent-soft --cta-text`.
- Palitra iliq: krem fon, jigarrang urg'u (`#8f5a2c`), qorong'i temada `#d8a066`.
- Sarlavha va hero matnlari — Georgia serif; qolgan matn — tizim sans shrifti.
- Har bir o'zgarish qorong'i temada ham tekshirilsin (tugma yuqori o'ng burchakda).

## Texnik chegaralar
- Faqat 3 ta fayl: `index.html`, `style.css`, `script.js`. Rasmlar — `images/`.
- Toza HTML/CSS/JS. Framework, npm, build qadami, CDN havolalari YO'Q — sayt oflayn ishlashi kerak.
- JS minimal: tema almashtirish, footer yili, rasm topilmasa zaxira. Yangi JS faqat zarur bo'lsa.
- Moslashuvchan bo'lsin: 700px dan kichik ekranda ham to'g'ri ko'rinsin.
- Parol, API kalit, shaxsiy hujjat ma'lumotlari faylga yozilmaydi.

## Ish qoidalari
- Qurishdan oldin qisqa reja ko'rsat (2-4 gap), keyin boshla.
- Kichik qadamlar bilan ishla: bitta so'rovga bitta aniq o'zgarish. So'ralmagan narsani qo'shma.
- Mavjud kod uslubiga moslash: bir xil chekinish, bir xil izoh uslubi (izohlar o'zbekcha).
- Matn yoki loyiha tafsilotini o'zim to'qib yozmayman — namuna matn qo'ysam, buni ochiq aytaman.
- Foydalanuvchining rasm/fayllarini o'chirmayman; o'zgartirish kerak bo'lsa, asl nusxasini saqlab qo'yaman.
- Ish tugagach, nima o'zgarganini qisqa va aniq tushuntiraman.
